# Ракета — портал для малого бизнеса

Бесплатные инструменты для предпринимателей: **200 000+ шаблонов и отраслевых вариантов документов**, **276 бизнес-калькуляторов**, **468 рабочих сервисов в 28 направлениях** и налоговый центр 2026. Всё считается и заполняется прямо в браузере — данные никуда не отправляются.

## Документы за минуту

Каталог объединяет базовые заполняемые документы с отраслевыми вариантами по нишам, услугам и сторонам сделки: договоры, акты, счета, соглашения, расписки, доверенности, заявления, уведомления, корпоративные, кадровые, личные и другие документы.

## 468 сервисов предпринимателя

Отдельный рабочий центр объединяет **28 направлений**: деньги и финансы, счета и оплаты, CRM, коммерческие предложения, договорный помощник, документы по ситуации, пакеты документов, кадры, самозанятые и подрядчики, налоги, контрагенты, реквизиты, прайс-листы, склад, маркетплейсы, маркетинг, продажи, отзывы, аналитика, проекты, закупки, бизнес-план, запуск бизнеса, база знаний, календарь, уведомления, помощник предпринимателя и «Мой бизнес».

**[Открыть все 468 сервисов →](https://tashev11.github.io/raketa/servisy.html)**

Сервисы используют единый движок: реестры, планировщики, чек-листы, генераторы, мастера, инструкции и аналитические карточки. Записи сохраняются в браузере; реестры можно выгружать в CSV/JSON, тексты — копировать и печатать.

## 276 калькуляторов для бизнеса

Отдельный центр калькуляторов охватывает **21 направление**: налоги, сотрудники, продажи, цена и маржинальность, прибыль, денежные потоки, кредиты, инвестиции, реклама, маркетплейсы, торговля, услуги, HoReCa, бьюти/фитнес, недвижимость, автобизнес, логистика, производство, арендный бизнес, франшизы и управленческие показатели.

**[Открыть все 276 калькуляторов →](https://tashev11.github.io/raketa/kalkulyatory.html)**

Примеры: точка безубыточности, маржа и наценка, LTV/CAC, ROMI, ROAS, кассовый разрыв, Burn Rate, Runway, кредит и лизинг, DSCR, NPV, IRR, Food Cost, юнит-экономика маркетплейсов, оборачиваемость товара, стоимость часа специалиста, окупаемость недвижимости, стоимость рейса, себестоимость производства и десятки других.

## Налоговый центр 2026

Не один калькулятор, а набор инструментов для ИП и ООО: налоговый диагноз, НДС на УСН, сравнение режимов, взносы ИП, прогрессивный НДФЛ, персональный календарь, стоимость сотрудника, резерв ЕНС, пени, ПСН, ФОТ команды, план авансов УСН и сценарии роста бизнеса.

## Главные возможности

- **Документы** — 200 000+ шаблонов и отраслевых вариантов
- **Сервисы** — 468 инструментов в 28 направлениях
- **Калькуляторы** — 276 расчётов в 21 направлении
- **Финансы** — P&L, ДДС, план-факт, дебиторка, кредиторка, кассовые разрывы
- **CRM** — клиенты, лиды, сделки, контакты, повторные продажи и причины отказов
- **Счета и оплаты** — счета, оплаты, просрочки, напоминания и сверки
- **Договорный помощник** — подбор договора, чек-листы, приложения, ТЗ, SLA, претензии
- **Кадры** — сотрудники, адаптация, KPI, отпуска, оборудование и увольнение
- **Закупки и склад** — заявки, поставщики, заказы, приёмка, остатки, ABC и неликвиды
- **Маркетинг и продажи** — контент-план, UTM, офферы, скрипты, follow-up и отзывы
- **Бизнес-план и запуск** — мастера запуска по нишам и финансовая модель
- **Календарь и уведомления** — налоги, договоры, оплаты, задачи, патенты и страховки
- **Налоги 2026** — УСН, ПСН, НПД, АУСН, НДС, взносы, НДФЛ, ЕНС и пени

## Как устроено

| Файл | Назначение |
|---|---|
| `index.html` | Портал: каталог документов, поиск и бизнес-инструменты |
| `servisy.html` | Центр 468 сервисов предпринимателя |
| `business-services-catalog.js` | 28 направлений и каталог сервисов |
| `business-services-app.js` | Общий движок реестров, планировщиков, мастеров и генераторов |
| `kalkulyatory.html` | Центр 276 бизнес-калькуляторов |
| `business-calculators-catalog.js` | 21 категория и полный перечень калькуляторов |
| `business-calculators-app.js` | Общий расчётный движок калькуляторов |
| `catalog-manifest.js` | Подключение расширений каталога документов |
| `catalog-runtime.js` / `catalog-virtual.js` | Виртуальная генерация отраслевых вариантов |
| `documents.html` | Каталог видов документов |
| `catalog.html` | Конструктор ниша → услуга → документ → стороны |
| `dokumenty.html` | Генератор документов |
| `nalogi-2026.html` | Базовый налоговый центр 2026 |
| `tax-rules-2026.js` | Единые ключевые лимиты и формулы 2026 |
| `home-directions.js` | 7 исходных направлений + вход во все сервисы и калькуляторы |
| `support.js` | Шаблонизатор и адаптивные стили |

Статическая версия работает на GitHub Pages. Данные сервисов, расчётов и черновиков сохраняются в браузере пользователя. Онлайн-проверки по внешним государственным и коммерческим базам требуют отдельного API и не подменяются фиктивными результатами.

## Запуск локально

```bash
python3 -m http.server 8743
```

Затем откройте http://localhost:8743

## Важно

Шаблоны, проверки и расчёты — типовые инструменты и ориентировочные результаты, а не юридическая, налоговая или бухгалтерская консультация. Для юридически значимых решений проверяйте актуальные данные и документы у профильного специалиста.
