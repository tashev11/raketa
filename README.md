# Ракета — портал для малого бизнеса

Бесплатные инструменты для предпринимателей: **200 000+ шаблонов и отраслевых вариантов документов** и налоговый центр 2026. Всё считается и заполняется прямо в браузере — данные никуда не отправляются.

## Документы за минуту

Каталог объединяет базовые заполняемые документы с отраслевыми вариантами по нишам, услугам и сторонам сделки: договоры, акты, счета, соглашения, расписки, доверенности, заявления, уведомления, корпоративные, кадровые, личные и другие документы.

## Все инструменты

- **Документы** — 200 000+ шаблонов и отраслевых вариантов документов
- **Налоги 2026** — налоговый диагноз, УСН, ПСН, НПД, АУСН, НДС и календарь
- **НДС 2026** — контроль порога и сравнение ставок 5%, 7% и 22% с вычетами
- **Патент 2026** — проверка лимита 20 млн ₽, численности работников, уменьшения на взносы и графика оплаты
- **Взносы ИП** — фиксированная часть и 1% с базы свыше 300 000 ₽
- **Какой режим выгоднее** — сравнение УСН, патента, НПД и АУСН
- **НДФЛ** — прогрессивная шкала и расчёт удержанного налога
- **Стоимость сотрудника** — зарплата, НДФЛ и страховые взносы работодателя
- **ФОТ команды** — стоимость нескольких сотрудников с премиями и дополнительными расходами
- **Потянет ли бизнес сотрудника** — выручка, маржа, расходы и точка окупаемости найма
- **ЕНС** — сколько зарезервировать под ближайшие налоговые обязательства
- **Пени** — оценка задолженности с учётом правил 2026 года
- **План УСН** — авансовые платежи по кварталам нарастающим итогом
- **Налоговый прогноз** — ориентировочное резервирование налогов по месяцам
- **Рост бизнеса** — сценарии +10%, +30%, +50% и предупреждения о налоговых порогах
- **Проверка реквизитов** — ИНН, ОГРН, БИК и расчётный счёт по контрольным суммам

## Как устроено

| Файл | Назначение |
|---|---|
| `index.html` | Портал: каталог документов, поиск и бизнес-инструменты |
| `catalog-manifest.js` | Подключение расширений каталога документов |
| `catalog-runtime.js` / `catalog-virtual.js` | Виртуальная генерация отраслевых вариантов |
| `documents.html` | Каталог видов документов |
| `catalog.html` | Конструктор ниша → услуга → документ → стороны |
| `dokumenty.html` | Генератор документов |
| `nalogi-2026.html` | Базовый налоговый центр 2026 |
| `tax-center-extra.js` | Стоимость сотрудника, ЕНС, пени и налоговый прогноз |
| `tax-center-extra-2.js` | ПСН, ФОТ команды, план УСН и сценарии роста |
| `tax-business-affordability.js` | Проверка окупаемости нового сотрудника |
| `support.js` | Шаблонизатор и адаптивные стили |

Ни сборки, ни серверного бэкенда — статические файлы на GitHub Pages. Данные расчётов и черновиков остаются в браузере пользователя.

## Запуск локально

```bash
python3 -m http.server 8743
```

Затем откройте http://localhost:8743

## Важно

Шаблоны и расчёты — типовые образцы и ориентировочные значения, а не юридическая или налоговая консультация. Для крупных или нетиповых сделок проверяйте документы и расчёты у профильного специалиста.
