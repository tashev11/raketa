# Масштабируемый каталог «Ракеты»

## Цель

Поддерживать 10 000–100 000 поисковых вариантов документов без копирования юридического текста и без раздувания `index.html`.

Формула каталога:

**базовый проверенный документ × ниша × услуга × сценарий сторон**

Пример:

- Договор оказания услуг
- Стоматология
- SEO-продвижение
- ИП → ООО

= `Договор оказания услуг: SEO-продвижение — ИП → ООО`

Юридическое тело наследуется от проверенного базового шаблона. Отраслевой вариант добавляет название ниши, конкретную услугу, поисковые теги и тип сторон.

## Что уже есть

`catalog-runtime.js` содержит:

- около 100 бизнес-ниш;
- более 100 услуг и работ;
- 4 B2B-сценария сторон;
- 4 типа коммерческих отношений: услуги, подряд/работы, поставка, аренда;
- до 5 документов на каждый сценарий;
- ограничитель в 30 000 генерируемых карточек за один проход.

## Сценарии сторон

Первый этап ориентирован на коммерческие B2B-документы:

- ИП → ООО
- ООО → ИП
- ООО → ООО
- ИП → ИП

Следующий слой можно добавить отдельно:

- самозанятый → ИП;
- самозанятый → ООО;
- физлицо → ИП;
- физлицо → ООО;
- ИП/ООО → физлицо (B2C).

Их нельзя бездумно смешивать с B2B, потому что B2C и отношения с самозанятыми требуют других юридических оговорок.

## Правило качества

Нельзя считать карточку новым юридическим шаблоном только потому, что изменилось название отрасли.

В интерфейсе рекомендуется использовать формулировку:

**«30 000+ шаблонов и отраслевых вариантов документов»**

а для базовых документов отдельно показывать количество юридически вычитанных основ.

## Следующие этапы

1. Подключить `catalog-runtime.js` перед созданием компонента.
2. Вынести базовые 83 документа из `index.html` в отдельные данные.
3. Перенести полнотекстовый поиск на компактный индекс.
4. Загружать полный текст документа только при открытии карточки.
5. Добавить отдельные посадочные URL для SEO: `/templates/<niche>/<service>/<document>/`.
6. Добавить генератор sitemap и SEO-страниц.
7. Добавить тесты, исключающие нелогичные комбинации.
8. Расширить словарь до 300–500 ниш и 2 000–5 000 реальных услуг.

## Важно для SEO

Не создавать десятки тысяч почти одинаковых HTML-страниц без уникальной ценности. Для индексируемой страницы должны отличаться как минимум:

- интент;
- заголовок;
- описание сценария;
- когда использовать;
- необходимые данные;
- риски;
- отраслевые условия;
- FAQ.

Карточки без достаточной уникальности лучше оставлять доступными через внутренний поиск, но не включать в sitemap до доработки содержания.
